## 🚀 Overview
A desktop application with a graphical user interface (GUI) designed to extract product information (names, prices, and ratings) from e-commerce websites and export the data into a structured CSV format. 

*Here’s the main interface of the E-Commerce Web Scraper:*

![img](https://github.com/Dharmendra0305/SCT_SD_4/blob/6f287c5973bee7b31f3b0097593b8fb3153402a0/1.png)

## ✨ Features
* **Interactive GUI:** Built with Java Swing for a user-friendly experience.
* **Live Web Scraping:** Uses Jsoup to extract DOM elements in real-time.
* **Data Export:** Seamlessly export scraped product data to a `.csv` file.
* **Error Handling:** Validates URLs and manages network timeouts gracefully.

## 💻 Tech Stack
* **Language:** Java (JDK 11 or higher recommended)
* **Framework:** Java Swing (UI)
* **Library:** [Jsoup 1.17.2](https://jsoup.org/) (HTML Parser)
* **Build Tool:** Maven

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/ecommerce-web-scraper.git](https://github.com/your-username/ecommerce-web-scraper.git)
   cd SCT_SD_4\src

2. Open the project in your IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Load Maven Dependencies: Ensure pom.xml is loaded so Jsoup is downloaded.
4. Run the Application: Execute the main method in WebScraper.java.

## 📖 Usage
1. Launch the application.
2. Enter the target URL (default test site: https://books.toscrape.com/).
3. Click Scrape to fetch product data into the table.
4. Click Export to CSV to save the results to your local machine.
